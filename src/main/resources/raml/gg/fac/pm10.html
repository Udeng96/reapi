미세먼지 API version 1.0

http://{domain}:{port}/api

화진데이터를 연계하여 response 하는 api
stat 요청에 page(default =1), rows(default=10) 파라미터가 추가되었습니다.

  • domain: required(string)

    API 서버가 설치된 도메인

  • port: required(integer)

    API 서버 접속 포트(80인 경우 생략)

/fac/pm10 get

미세먼지 API

get

미세먼지 계측기 정보요청

get /fac/pm10

미세먼지 계측기 정보요청

  • Response

HTTP status code 200

Body

Media type: application/json

Type: array of object

Items: gisInfo

  • facId: required(string)

    시설물 id

  • facNm: required(string)

    시설물 명칭

  • addr: required(string)

    시설물 주소정보

  • lat: required(number)

    위도

  • lng: required(number)

    경도

  • type: required(string)

    시설물 타입 / 혹은 구분 코드(분류코드로 활용할 예정)

  • useYn: required(boolean)

    사용유무

  • state: required(string)

    ON - 정상, OFF - 종료, ERROR - 비정상 이후 필요한 상태에 대해 정의 후 사용 바람

  • updDtm: (string)

    장비 혹은 센서의 업데이트 시각이 필요한 경우 사용 (form - yyyyMMDDHHmmSS)

  • data: (union of object or nil)

    시설물 별로 데이터를 함께 가져가야하는 경우 사용

미세먼지 전체 리스트

  • Request
  • Response

Query Parameters

  • startDtm: (string - default: 20220304 (금일날짜로 조회))

    조회 시작 일자 format-yyyyMMdd

  • endDtm: (string - default: 20220304 (금일날짜로 조회))

    조회 종료일자 format-yyyyMMdd

  • dataType: required(string - default: H)

    연간(Y), 월간(M), 일간(D) , 시간 (H) , 10분단위(M)

  • row: (number)

    데이터 갯수 지정

  • page: (number - default: 1)

    요청 페이지 넘버, -1로 요청시 전체 조회

  • rows: (number - default: 10)

    한페이징 표출 row 수
